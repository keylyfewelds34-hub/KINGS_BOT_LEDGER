# KINGS BOT — PRE-LEGACY BOT STATE MANIFEST

## CLASSIFICATION

PRE-LEGACY DEVELOPMENT BASELINE

This state represents the furthest known development condition of KINGS BOT before Legacy/V6 experimentation began.

It is intentionally described as a development baseline, not a completed release.

---

## KNOWN DEVELOPMENT CONDITION

KINGS BOT had substantial operational architecture and member-facing behavior, but development was still active.

Known systems included settlement-aware BTC/Kalshi analysis, cycle tracking, signal/callout behavior, whale monitoring, Discord delivery, charting, backup/dashboard tasks, and asynchronous runtime supervision.

At the same time, unresolved structural/runtime regressions were being debugged around functions such as `chart_loop()`, `cycle_timer_loop()`, and chart-building code.

---

## HISTORICAL RULE

Future experimental success must not be used to rewrite this baseline as if those later features already existed.

Future experimental failure must not be used to diminish functionality that is documented as having existed.

---

## PROTECTED INTERPRETATION

The pre-Legacy state may contain:

- Working systems
- Partially working systems
- Incomplete features
- Known defects
- Unverified repairs
- Missing source recovery

All of those facts can coexist.
