# KINGS BOT — PRE-LEGACY DEVELOPMENT BASELINE

## STATUS

PROTECTED HISTORICAL EVIDENCE VAULT

This directory preserves the state of KINGS BOT development as it was understood before Legacy/V6 experimentation began.

It is not a claim that KINGS BOT was complete, production-certified, or free of defects.

It is not reconstructed production source.

Nothing in this directory authorizes changes to production bot behavior.

---

## PURPOSE

Preserve what existed before old Legacy/V6 concepts are studied alongside newer KINGS BOT development.

The goal is to keep historical state, unfinished work, known behavior, known regressions, source evidence, and recovery limitations clearly separated from experimental work.

---

## PROTECTION RULES

1. Do not rewrite historical evidence to match later experimental results.
2. Do not describe incomplete evidence as complete source code.
3. Do not treat screenshots or snippets as authoritative full-file replacements.
4. Do not use this directory as a working development area.
5. Legacy/V6 experimentation belongs in the isolated experimental branch and quarantine area.
6. Production integration requires explicit specification, QA/QC, and Product Owner approval.
7. If a complete original bot source snapshot is later recovered, preserve it separately and record its exact provenance and commit.
